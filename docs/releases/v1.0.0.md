# Peripheral Battery Tray v1.0.0

A standalone battery monitor for **64-bit Windows 10 and 11**. Python and the required libraries are bundled.

## Download and run

- **Portable ZIP.** Extract it to a permanent folder and run `PeripheralBatteryTray.exe`.
- **Setup EXE.** Installs for the current user and adds a Start menu shortcut.
- **Standalone EXE.** Runs directly without installation.
- **SHA256SUMS.txt.** Use it to verify the downloads. The binaries are unsigned.

Connect a supported USB receiver and select **Find USB**. A Bluetooth adapter is needed only for **Find Bluetooth**. New installations enable startup at Windows sign-in. It can be disabled in Settings. Use **Pin tray icons in Windows** to open the system controls for icon visibility next to the clock.

## What's included

- Battery percentage, connection status and last successful reading for each device.
- Separate or combined tray icons. Separate icons can show device silhouettes or battery indicators, with an optional percentage badge.
- Configurable low-charge alerts, polling frequency and device visibility. Light, dark and system themes. English and Russian.
- Existing IPI Haze X Pro, Logitech G PRO X 2 LIGHTSPEED and Bluetooth LE Battery Service readers. Experimental exact-percentage discovery for selected Logitech Bolt, Unifying and LIGHTSPEED USB receivers.
- Local settings and rotating diagnostics. No telemetry.

## По-русски

Автономная утилита для **64-разрядных Windows 10 и 11**. Распакуйте портативный ZIP и запустите `PeripheralBatteryTray.exe` либо используйте файл `-setup.exe` для установки с ярлыком в меню «Пуск». Python уже включён. Для проверки файлов используйте `SHA256SUMS.txt`.

- Подключите USB-приёмник и нажмите **Поиск USB**. Bluetooth нужен только для кнопки **Поиск Bluetooth**.
- В настройках можно выбрать силуэты мыши и наушников или индикаторы батареи, настроить уведомления и отключить автозапуск. Кнопка **Закрепить значки в Windows** открывает системные параметры трея.
- Сохранено чтение IPI Haze X Pro, Logitech G PRO X 2 LIGHTSPEED и стандартного BLE Battery Service. Для некоторых приёмников Logitech добавлен экспериментальный поиск через HID++ 2.0. Приложение показывает процент только после получения корректного показания устройства.
